# 📋 Operação no Gemini

## Como usar
1. Abra **Gemini** (gemini.google.com) com modelo de geração de imagem ativo
2. Cole **um prompt por vez**
3. Se a primeira tentativa não acertar a composição, peça *"regenere com mais espaço negativo no topo"* ou *"regenere com menos elementos no fundo"* — ajustes incrementais funcionam melhor que reescrever
4. Se o Gemini insistir em colocar texto na imagem (acontece): adicione no final do prompt *"absolutely no text, no letters, no typography of any kind — pure photograph"*

## Composição para sobrepor texto no Canva

Cada prompt foi escrito com **áreas de espaço negativo intencional**. Use essa indicação ao posicionar a tipografia:

| Peça | Espaço para texto |
|---|---|
| POST 01 (hero) | Upper 2/3 da imagem |
| POST 02 (still life) | Lado direito |
| POST 03 (macro) | Lado direito (2/3 da imagem) |
| POST 04 (linha frascos) | Upper 2/3 |
| POST 05 (vela) | Upper 2/3 (na sombra) |
| POST 06 (livro) | Upper half |
| REEL 01 (mãos) | Top 25% + Bottom 30% |
| REEL 02 (difusor) | Upper third + lateral esquerda |
| REEL 03 (hero vertical) | Top 35% + Bottom 35% |

## Substituições de produto

O prompt menciona "small dark amber bottle 10ml" como padrão. Para variações com outros produtos da campanha, troque por:

- **Frasco maior**: *"50ml dark amber pharmaceutical bottle, taller and wider"*
- **Sérum Cleópatra**: *"small dark amber dropper bottle with glass pipette dropper instead of cap, 30ml"*
- **Pote de manteiga vegetal**: *"small flat ceramic jar with white screw lid, 100g size"*
- **Livro (POST 06)**: *"closed hardcover book with terracotta linen cover instead of moss green"*
